# Фото и часы — заставка для Android TV

Лёгкая заставка (`DreamService`) для Android TV: семейная фоторамка с фото и видео из Telegram, плавной сменой и
эффектом Ken Burns, крупные часы и дата по-таджикски, время намаза, погода (Open-Meteo) и курсы валют к сомони
(официальный курс Нацбанка Таджикистана). Проверено на Artel R4 / Android TV 11.

Интерфейс настроек и ответы бота — на русском. Курсы и намаз рассчитаны на Таджикистан; оба блока, как и погоду,
можно выключить в настройках.

- Пакет: `tj.tvsaver`, сервис заставки: `tj.tvsaver/.SaverDream`
- Без зависимостей (только Kotlin stdlib). Сеть для погоды и курсов используется только пока заставка на экране.
  Единственная фоновая задача — проверка Telegram раз в ~20 минут, и только если бот подключён.
- Погода обновляется раз в 30 мин, курсы — раз в 6 ч; последние значения кешируются и показываются без интернета.
- Часы, дата, намаз, погода и курсы — неподвижной строкой сверху.
- Стрелки ← → и кнопки Media Next/Previous листают фото и видео, любая другая кнопка пульта закрывает заставку.

## Структура

```
app/src/main/java/tj/tvsaver/
  SaverDream.kt       — сама заставка: верхняя строка (часы, погода, курсы), расписание обновлений, Telegram
  Slideshow.kt        — источники фото/видео, декодер под 1920×1080, crossfade + Ken Burns (≤ 2 битмапа в памяти)
  SeenPhotos.kt       — какие фото уже показаны (новые идут первыми)
  VideoLayer.kt       — видео поверх фото, звук потише громкости ТВ (MediaPlayer + SurfaceView на время ролика)
  Backdrop.kt         — размытый фон для вертикальных фото и видео
  Prayer.kt           — время намаза с shuroiulamo.tj (таблица на месяц, кеш)
  NightSleep.kt       — ночное автовыключение через системное «время до сна»
  Sources.kt          — HTTP, Open-Meteo, XML Нацбанка (nbt.tj) и запасной open.er-api.com
  DataCache.kt        — кеш последних погоды/курсов (SharedPreferences)
  Prefs.kt            — настройки, список городов и валют
  TajikDate.kt        — дата по-таджикски
  SettingsActivity.kt — экран настроек под пульт
  SettingRow.kt       — переиспользуемая строка настроек «Название … Значение»
  WeatherIconView.kt  — погодные значки, нарисованные кодом; коды WMO → текст
  TelegramApi.kt      — минимальный клиент Bot API (getUpdates, getFile, sendMessage)
  TelegramSync.kt     — владелец/разрешённые люди, сохранение фото с подписями
  TelegramJob.kt      — фоновая проверка бота раз в ~20 минут (JobScheduler)
```

## Сборка

Нужны JDK 17–22 (проверено на 21) и Android SDK (platform 35, build-tools 35). Gradle 8.9 не запускается на более
новых JDK: JDK 25 из свежей Android Studio не подойдёт, ошибка выглядит как `What went wrong: 25.0.3`.
Путь к SDK задаётся переменной `ANDROID_HOME` или строкой `sdk.dir=...` в `local.properties` (файл не хранится в git).

```bash
# macOS: brew install openjdk@21
export JAVA_HOME="$(brew --prefix openjdk@21)/libexec/openjdk.jdk/Contents/Home"
export ANDROID_HOME="$HOME/Library/Android/sdk"

./gradlew assembleRelease
# → app/build/outputs/apk/release/app-release.apk
```

Release подписывается вашим локальным отладочным ключом — для установки через adb этого достаточно.
Для публикации в магазине приложений настройте свой ключ в `app/build.gradle.kts`.

## Установка на ТВ

Включите на телевизоре отладку по сети и подставьте его адрес. Команды ниже используют переменную `TV`:

```bash
TV=192.168.1.50:5555   # IP вашего телевизора

adb connect $TV
adb -s $TV install -r app/build/outputs/apk/release/app-release.apk

# сделать заставкой
adb -s $TV shell settings put secure screensaver_components tj.tvsaver/.SaverDream
adb -s $TV shell settings put secure screensaver_enabled 1

# запустить сразу
adb -s $TV shell am start -n com.android.systemui/.Somnambulator
```

## Семейная фоторамка через Telegram

Фото, отправленное боту с телефона, появляется в заставке. Подпись к фото и имя отправителя
показываются внизу справа: «от Мамы · Самарканд».

- Пока заставка на экране, бот опрашивается постоянно (долгий опрос), и фото показывается вне очереди через 1–3 секунды.
- Когда заставки нет, телевизор раз в ~20 минут забирает новые фото в фоне (системный JobScheduler, без постоянной службы).
  Важно: Telegram хранит неполученные ботом сообщения только 24 часа. Если ТВ был выключен дольше, фото придётся отправить заново.
- Фото хранятся в папке приложения (`files/telegram`), до 300 штук; самые старые удаляются автоматически.
  Видео (до 20 МБ, обычным видео, не файлом) показываются со звуком потише громкости ТВ (`VOLUME` в `VideoLayer.kt`); храним до 30 видео.
  Всё показывается по кругу; пока ничего нет — на экране подсказка, кому присылать.
- Фото принимаются только от владельца и одобренных им людей.

### Подключение

Каждому телевизору нужен свой бот: токен остаётся только на ТВ, в коде и в репозитории его нет.

1. В Telegram: **@BotFather** → `/newbot` → имя и адрес бота → получите токен `123456:ABC...`.
2. Передайте токен заставке:
   ```bash
   adb -s $TV shell am start -n tj.tvsaver/.SettingsActivity --es tg_token "123456:ABC..."
   ```
   На ТВ откроются настройки. В строке «Telegram-бот» будет написано: `@ваш_бот: отправьте боту /start 1234`.
3. С телефона отправьте боту `/start 1234` (код с экрана). Вы — владелец.
   Бот спросит, как подписывать ваши фото: например, `Папы` → на экране «от Папы».
4. Остальные члены семьи пишут боту `/start`, а вы получаете кнопки «✅ Разрешить / Отклонить».
   После одобрения бот спросит подпись для этого человека (`Мамы`, `бабушки`; `-` — имя из профиля).
   Команда `/people` показывает список людей, их подписи и кнопки «✏️ Подпись» и «Убрать».
   Убрать фото или видео с ТВ: `/list` → кнопка «Удалить» или ответить на него (или на ответ бота «✅ …») словом `удалить`.
   Удалить может автор или владелец.
5. Удалить все фото из Telegram: Настройки заставки → «Из Telegram» → OK дважды.
   Отключить бота: `adb -s $TV shell am start -n tj.tvsaver/.SettingsActivity --ez tg_off true`.

## Свои фото из папки

Фото можно положить и напрямую на ТВ, без Telegram:

```bash
# доступ к папке с фото (Android 11); то же с пульта: настройки → «Свои фото из папки» → OK → «Разрешить»
adb -s $TV shell pm grant tj.tvsaver android.permission.READ_EXTERNAL_STORAGE

adb -s $TV shell mkdir -p /sdcard/Pictures/Screensaver
adb -s $TV push фото.jpg /sdcard/Pictures/Screensaver/
adb -s $TV push ~/Pictures/Отпуск/. /sdcard/Pictures/Screensaver/   # целую папку
```

Подходят JPEG, PNG, WebP, HEIC. Фото любого размера: заставка сама уменьшает их под экран.
Новые файлы подхватываются на следующем круге слайд-шоу.

## Время намаза

Следующий намаз — в верхней строке: крупно время, под ним «Намоз – Аср». Названия: Бомдод, Пешин, Аср, Шом, Хуфтан.

- Источник — официальное расписание Совета улемов / Исламского центра РТ: [shuroiulamo.tj/ru/namaz](https://shuroiulamo.tj/ru/namaz).
  Заставка запрашивает таблицу на месяц (`POST /ru/namaz/ntime`, `fmonth`, `fyear`) и хранит её в кеше:
  весь месяц работает без интернета. Обновление — если нет данных на сегодня или им больше 3 дней.
- Следующий месяц сайт публикует не всегда заранее. Тогда после Хуфтана последнего дня месяца
  Бомдод берётся из конца Хуфтана в таблице («19:07 - 05:20» → 05:21).
- Для других городов из настроек применяется сдвиг в минутах относительно Душанбе (как в расписаниях Исламского центра).
- Выключить: Настройки заставки → «Время намаза».

## Ночное автовыключение

С 22:00 до 07:00 заставка ставит системное «время до сна» (`settings secure sleep_timeout`) на 2 часа
(в настройках: выкл / 1 / 2 / 3 ч), днём возвращает прежнее значение (24 ч). То есть если заснули под заставку,
через 2 часа без пульта ТВ сам уходит в режим ожидания. Видео в плеерах это не прерывает.

Нужно разрешение, которое выдаётся только через adb:
```bash
adb -s $TV shell pm grant tj.tvsaver android.permission.WRITE_SECURE_SETTINGS
```
Отмена: `pm revoke ...` и `adb shell settings put secure sleep_timeout 86400000`.

## Настройки

Открыть: иконка «Фото и часы» в лаунчере. Там: «Запустить заставку», интервал смены фото, город, показ погоды/курсов/намаза,
список валют (по умолчанию USD и RUB), доступ к фото.

То же с компьютера через adb, в том числе произвольный город по координатам:

```bash
adb -s $TV shell am start -n tj.tvsaver/.SettingsActivity \
  --es city_name "Самарканд" --ef lat 39.65 --ef lon 66.96
adb -s $TV shell am start -n tj.tvsaver/.SettingsActivity --es currencies "USD,RUB,EUR"
adb -s $TV shell am start -n tj.tvsaver/.SettingsActivity --ei interval 60
```

Новые настройки применяются при следующем запуске заставки.

## Источники данных

- **Погода**: [Open-Meteo](https://open-meteo.com/) без ключа (`api.open-meteo.com/v1/forecast`).
- **Курсы**: официальный XML Нацбанка Таджикистана
  `https://nbt.tj/ru/kurs/export_xml.php?date=ГГГГ-ММ-ДД&export=xmlout`
  (формат `ValCurs/Valute/CharCode/Nominal/Value`). Проверено на живом ответе 18.10.2026:
  - без параметра `date` сервер отвечает 500, поэтому дата передаётся всегда (сегодня по Душанбе);
  - на выходные и будущие даты сервер отдаёт последний действующий курс;
  - в заголовке XML написано `windows-1251`, а байты на самом деле в UTF-8.
  Если nbt.tj недоступен (у них бывают сбои), берётся [open.er-api.com](https://open.er-api.com/v6/latest/TJS)
  и через час заставка снова пробует Нацбанк.

## Полная отмена

```bash
# вернуть прежнюю заставку (например, Google Backdrop)
adb -s $TV shell settings put secure screensaver_components com.google.android.backdrop/.Backdrop
# вернуть «время до сна», если включали ночное автовыключение
adb -s $TV shell settings put secure sleep_timeout 86400000
# удалить приложение
adb -s $TV uninstall tj.tvsaver
# (необязательно) удалить свои фото
adb -s $TV shell rm -r /sdcard/Pictures/Screensaver
```
